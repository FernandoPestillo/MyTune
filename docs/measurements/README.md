# Evidências da Release inicial 1.0.0

As pastas são organizadas por etapa de construção: precisão, seleção automática, afinações, personalização e refinamentos dos headstocks. Todas compõem a mesma Release inicial **1.0.0**.

Os registros brutos de execução permanecem íntegros, incluindo identificadores internos de builds, caminhos originais, datas, hashes, nomes de pacotes/dependências e medições. Esses identificadores não representam releases públicas anteriores. Alterá-los confundiria a evidência dos artefatos realmente testados.

Os resultados do APK publicado como 1.0.0 ficam em `release_1_0_0/` e no [relatório de lançamento](../RELEASE_1_0_0.md). Os nomes internos dos arquivos DataStore e seus formatos também são preservados para manter os dados já salvos.
